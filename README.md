# RizeTracker Dashboard

This project provides a web dashboard for the RizeTracker extension, offering activity tracking and productivity analytics.

## Hosted Dashboard

A live deployment is available at:

https://example.com

## Development

```bash
npm install
npm run dev
```

The repository includes a local `react-visual-effects` helper package that powers the glow styling in
the Screen Assistant. Running `npm install` will automatically link the package from `packages/react-visual-effects`.

## Environment Variables

Configure Supabase credentials in a `.env` file or via your hosting provider:

```
VITE_SUPABASE_URL=your_supabase_project_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
VITE_SCREEN_ASSISTANT_URL=https://your-project.functions.supabase.co/screen-assistant
```

The `VITE_SCREEN_ASSISTANT_URL` should point to the Supabase Edge Function described below.

## Screen-aware assistant setup

This project ships with a Supabase Edge Function that accepts a screenshot and a natural language
question, then forwards both to OpenAI's vision-capable models. To deploy it:

1. Ensure the Supabase CLI is installed and authenticated.
2. Set the OpenAI API key for the function: `supabase secrets set --project-ref <ref> OPENAI_API_KEY=sk-...`
3. Deploy the function: `supabase functions deploy screen-assistant`.
4. Update `VITE_SCREEN_ASSISTANT_URL` with the deployed endpoint (shown in the CLI output).

Once deployed, open the "Screen Assistant" tab in the dashboard, share your screen, capture a screenshot,
and ask the assistant a question. The captured frame and question will be posted to the Edge Function,
which responds with an answer generated by the configured OpenAI model.

## Deployment

The `src/` folder contains a Vite + React app that can be deployed to services like Vercel. Set the above environment variables in the hosting platform's settings before deploying.

## Features

- Supabase authentication so users log into the same account as the extension.
- Analytics view with charts for activity over time, productivity scores, and Pomodoro completion stats.
